# boss-assisant — Boss 直聘自动投递助手增强版

这是一个专为 Boss 直聘职位列表页设计的 Tampermonkey/篡改猴自动投递脚本。支持按岗位名称、岗位详情、公司名称、薪资下限及外包公司名单筛选。

## 来源与改进

本项目由 **Nico-human** 维护，基于 [muyuniao/boss-auto-apply](https://github.com/muyuniao/boss-auto-apply) 开发，原作者为 **muyuniao**。保留原项目版权声明和提交历史，以 MIT 许可证发布。

增强版主要改进：

- 岗位名称、岗位详情、公司名称分别设置包含和排除关键词，包含规则优先。
- 薪资下限按 K/月设置，以岗位标价下限进行筛选。
- 内置外包公司名单，支持一键排除及公司包含关键词优先放行。
- 配置自动保存，提供筛选测试和浏览器面板验证。

当前版本：**0.3.0**。更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 文件说明

- `boss-auto-apply.user.js`：可直接安装到 Tampermonkey 的用户脚本。
- `data/outsourcing-companies.json`：外包公司名称、别名及 GitHub 来源，维护名单时修改此文件。
- `scripts/sync-outsourcing.cjs`：把名单同步到用户脚本，安装时仍只需一个 `.user.js` 文件。
- `tests/filters.test.cjs`：筛选规则和模拟投递流程测试。

## 安装与使用

1. 在浏览器中安装 **Tampermonkey / 篡改猴** 插件。
2. 点击 [安装增强版脚本](https://raw.githubusercontent.com/Nico-human/boss-assisant/main/boss-auto-apply.user.js)，在 Tampermonkey 中确认安装。若浏览器只显示源码，可复制本仓库的 `boss-auto-apply.user.js` 全部代码并手动新建脚本保存。安装后通过脚本管理器检查更新即可获取 GitHub 上的新版本。

   本增强版目前通过 GitHub 发布。若已安装原版或旧 fork 版本，请先停用旧脚本，避免同时运行；增强版使用独立的脚本名称和 namespace，篡改猴中的旧版配置需重新设置。

3. 自行登录 Boss 直聘网页版。
4. 打开 Boss 直聘职位页面，例如：
   - `https://www.zhipin.com/web/geek/job` （搜索结果页）
   - `https://www.zhipin.com/web/geek/job-recommend` （推荐职位页）
5. 页面右下角将自动挂载「Boss 自动投递助手增强版」控制面板。
6. 根据需要设置关键词、薪资下限及外包过滤，点击 **「开始」** 即可自动开始后台投递。配置会自动保存。

## 筛选规则

| 配置 | 匹配范围与行为 |
| --- | --- |
| 岗位名称包含 / 排除关键词 | 仅匹配岗位名称 |
| 岗位详情包含 / 排除关键词 | 仅匹配详情接口的职位描述，不混入公司名、薪资、地址等信息 |
| 公司名称包含 / 排除关键词 | 匹配招聘公司的展示名、可读取到的全称；不匹配详情中提到的合作公司 |
| 薪资下限 | 输入 K/月，以 `1` 为步长，如 `15` 表示 15000 元/月；留空或 `0` 不限制，仅比较岗位薪资范围的最低值 |
| 一键排除外包公司 | 默认关闭，开启后按本地维护的公司名称 / 别名名单排除 |

- 多个关键词仅用半角或全角逗号、分号（`,，;；`）分隔，换行和空格不作为分隔符。同一包含框命中任一词即可，不区分英文大小写；不同维度同时设置时需要分别满足。
- **包含优先于排除**：同一字段命中包含关键词后，忽略该字段的排除规则。例如岗位名称包含和排除都填 `android`，Android 岗位通过该项筛选。
- 岗位名称和岗位详情之间，同一个关键词同时用于包含和排除时，已匹配的包含词也优先。例如岗位名包含 `android`，详情排除 `android,外包`，Android 不导致排除，详情中的“外包”仍会排除。
- **公司包含优先于外包名单**：公司包含填 `外企德科`，即使同时在公司排除中填写它、并开启外包过滤，外企德科仍可通过公司筛选；薪资、岗位关键词和原有的活跃度、已沟通等检查继续生效。
- 薪资门槛填 `15`：`14-25K` 跳过，`15-25K` 通过；`14-25K·16薪` 仍按 `14K` 比较。可输入 `14`、`15`、`16` 等整数，不接受 `14.5`。支持识别标价中的 K、千、万、元及显式标注的年薪（除以 12），不设置薪资上限。旧版已保存的元/月配置会按 K/月展示，例如 `20000` 显示为 `20`。
- 设置薪资门槛后，面议、日薪、时薪及无法识别的标价会跳过。设置详情关键词后，无法获取职位描述也会跳过，并在日志显示原因。
- 新增选项默认留空/关闭，原有详情关键词会保留。详情筛选现在只检查职位描述，旧配置若依赖公司名等混合匹配，请移至相应的名称筛选框。

## 外包公司名单与维护

GitHub 已有专门维护名单的项目，本项目首批整理了 40 家公司，来源为 [grancode/outsourcing](https://github.com/grancode/outsourcing/blob/master/README.md) 和 [iwtkings/waibao-company](https://github.com/iwtkings/waibao-company/blob/main/README.md)。每条数据记录来源 ID、公司名称及用于匹配的别名。

这是社区整理的辅助筛选名单，不保证完整或适用于这些公司的每个岗位。采用公司名称包含别名的方式匹配，不根据“科技”“信息”等泛化词猜测外包；可能存在遗漏或误判，可通过公司包含关键词明确放行。

修改 `data/outsourcing-companies.json` 后运行：

```bash
npm run sync:outsourcing
npm run check
npm test
```

提交数据和同步后的脚本即可。名单随脚本分发，运行时不请求远程名单；已安装脚本需更新才能获取名单变更。

## 核心设计与特性

- **无感自动保存**：移除了手动的“保存”按钮。面板上对复选框和关键词输入框的任何改动，都会在后台自动、实时、无感地保存，不丢失输入焦点。
- **固定的投递等待**：
  - **投递间隔**：自动锁定在 **4秒 至 10秒 之间随机等待**，控制连续请求频率。
  - **翻页等待**：固定锁定为 **3秒** 自动翻页或滚动。
- **每日投递上限**：每日最大投递额度固定锁死在 **150 份**。一旦今天投递达到 150 份，脚本会安全终止并提示“已达每日上限”。
- **BOSS 活跃度过滤**：固定只投递 **两周内活跃** 的 BOSS。当 BOSS 活跃时间超过 14 天，自动跳过投递并提示 `boss活跃度未达标,已过滤`。
- **多维筛选机制**：
  - 支持岗位名称、详情、公司名称关键词、薪资下限及外包名单过滤，包含规则优先。
  - 移除了试运行和数据检测等繁琐调试工具，直接面向真实投递，点击「开始」即刻行动。
- **二次确认智能记录**：对 Boss 直聘常见的 `开聊提醒` (二级确认) 默认按投递成功记录。

## 注意事项

- 自动投递使用的是您当前浏览器登录的 Boss 页面原生接口，脚本**绝不**收集或上传您的个人数据或密码。
- 脚本不会突破、绕过 Boss 官方的滑块验证码或账号风控。如果弹出验证码，请手动完成即可。
- 如果提示“今日沟通上限”或触发风控，脚本会自动结束。建议合理规划每日投递。

## 本地代码检查 (开发者)

如果您本机安装了 Node.js：

```bash
npm run check
npm test
```

`check` 检查 JavaScript 语法及外包名单是否同步；`test` 使用 Node.js 自带的测试工具验证筛选规则，并通过模拟接口验证投递前过滤，不会发送真实投递请求。两项检查均无需安装依赖。

浏览器面板检查需先 `npm ci`，再运行 `npm run test:browser`。默认使用 macOS 的 Google Chrome，也可通过 `CHROME_PATH` 指定浏览器路径。测试使用独立的无头浏览器并拦截全部页面请求，检查自动保存、刷新恢复、输入焦点、数值校验及布局，不进行真实投递。
